# TGMP Backend Python



## Development Guidelines

The Backend is Python connexion openapi-server. Python models are automatically generated from the OpenAPI Specification
and extended with custom logic (services, mappers, persistence). It's important to follow the steps described below in
order to make changes to the code in the right way.


### 1. Update OpenAPI Spec

The file is a located in the `openapi` directory.

Latest version of the API Spec can be found here: [/tempogeopolitical-map/tgpm-openapi](https://gitlab.com/tempogeopolitical-map/tgpm-openapi), `main` branch

### 2. Generate Python Models from the OpenAPI Spec

1. Navigate to the `root` directory
2. Execute `scripts/openapi.sh`
3. It will create files in the `scr/@generated` with models.

### 3. Run Tests

### 4. Make changes to the business logic (but not to the models)

Do not manually edit the `scr/@generated` directory, it's always autogenerated.

1. Make changes in the `src/main` if needed
2. After the updates are done, verify that the app works
