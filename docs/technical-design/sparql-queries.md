# SPARQL Queries

Full templates used by the backend. Variables in `{curly_braces}` are Python `.format()`
placeholders injected at runtime.

---

## Events v2 — main paginated query

**Source:** `src/main/event_resolver/persistence/repository/events_v2_storage.py` — `_MAIN_QUERY_TEMPLATE`

```sparql
SELECT DISTINCT
  ?item ?itemLabel ?itemType
  ?startTime ?endTime
  ?description
  ?imageUrl
  ?wikipediaUrl
  (GROUP_CONCAT(DISTINCT ?countryId;     separator="|") AS ?countryIds)
  (GROUP_CONCAT(DISTINCT ?countryLabel;  separator="|") AS ?countryLabels)
  (GROUP_CONCAT(DISTINCT ?locationId;    separator="|") AS ?locationIds)
  (GROUP_CONCAT(DISTINCT ?locationLabel; separator="|") AS ?locationLabels)
  (GROUP_CONCAT(DISTINCT ?coordStr;      separator="|") AS ?coordStrs)
WHERE {
  SERVICE wikibase:label {
    bd:serviceParam wikibase:language "en".
  }

  {type_filter}
  ?item wdt:P31 ?itemType.

  OPTIONAL { ?item wdt:P580 ?startTimeIndicator. }
  OPTIONAL { ?item wdt:P585 ?pointInTime. }
  BIND(IF(BOUND(?startTimeIndicator), ?startTimeIndicator, ?pointInTime) AS ?startTime)

  OPTIONAL { ?item wdt:P582 ?endTime. }

  OPTIONAL {
    ?item schema:description ?description.
    FILTER(LANG(?description) = "en")
  }

  OPTIONAL { ?item wdt:P18 ?imageUrl. }

  OPTIONAL {
    ?article schema:about ?item ;
             schema:isPartOf <https://en.wikipedia.org/> ;
             schema:name ?wpTitle .
    BIND(
      IRI(CONCAT("https://en.wikipedia.org/wiki/", ENCODE_FOR_URI(?wpTitle)))
      AS ?wikipediaUrl
    )
  }

  OPTIONAL {
    ?item wdt:P17 ?countryEntity.
    ?countryEntity rdfs:label ?countryLabel.
    FILTER(LANG(?countryLabel) = "en")
    BIND(REPLACE(STR(?countryEntity), "http://www.wikidata.org/entity/", "") AS ?countryId)
  }

  OPTIONAL {
    ?item wdt:P276 ?locationEntity.
    ?locationEntity rdfs:label ?locationLabel.
    FILTER(LANG(?locationLabel) = "en")
    BIND(REPLACE(STR(?locationEntity), "http://www.wikidata.org/entity/", "") AS ?locationId)
    OPTIONAL {
      ?locationEntity wdt:P625 ?coord.
      BIND(CONCAT(STR(geof:latitude(?coord)), ",", STR(geof:longitude(?coord))) AS ?coordStr)
    }
  }

  {location_filter}

  FILTER(?startTime >= "{timeslot_start}"^^xsd:dateTime)
  FILTER(?startTime <= "{timeslot_end}"^^xsd:dateTime)
}
GROUP BY ?item ?itemLabel ?itemType ?startTime ?endTime ?description ?imageUrl ?wikipediaUrl
ORDER BY DESC(?startTime)
LIMIT {page_size}
OFFSET {offset}
```

### `{type_filter}` injection

Generated by `WikidataClassEnum.to_sparql_values_block(types)`:

```sparql
-- No filter (all types):
VALUES ?itemType { wd:Q52110228 wd:Q484652 wd:Q1127126 wd:Q100906234 wd:Q17195514
                   wd:Q3002772 wd:Q1139665 wd:Q2635077 wd:Q1335818 wd:Q71266556 }

-- Filtered (e.g. types=["WARFARE_AND_ARMED_CONFLICTS"]):
VALUES ?itemType { wd:Q71266556 }
```

### `{location_filter}` injection

Generated by `_build_location_filter(filters)`:

```sparql
-- No filter:
(empty string)

-- regions only:
VALUES ?regionCountry { wd:Q183 wd:Q142 wd:Q145 ... }
?item wdt:P17 ?regionCountry.

-- countries only:
VALUES ?iso3Code { "GBR" "FRA" }
?isoCountry wdt:P298 ?iso3Code.
?item wdt:P17 ?isoCountry.

-- regions AND countries (UNION = OR semantics):
{
  VALUES ?regionCountry { wd:Q183 ... }
  ?item wdt:P17 ?regionCountry.
} UNION {
  VALUES ?iso3Code { "GBR" }
  ?isoCountry wdt:P298 ?iso3Code.
  ?item wdt:P17 ?isoCountry.
}
```

## Events v2 — COUNT query

**Source:** `src/main/event_resolver/persistence/repository/events_v2_storage.py` — `_COUNT_QUERY_TEMPLATE`

```sparql
SELECT (COUNT(DISTINCT ?item) AS ?total)
WHERE {
  {type_filter}
  ?item wdt:P31 ?itemType.

  OPTIONAL { ?item wdt:P580 ?startTimeIndicator. }
  OPTIONAL { ?item wdt:P585 ?pointInTime. }
  BIND(IF(BOUND(?startTimeIndicator), ?startTimeIndicator, ?pointInTime) AS ?startTime)

  {location_filter}

  FILTER(?startTime >= "{timeslot_start}"^^xsd:dateTime)
  FILTER(?startTime <= "{timeslot_end}"^^xsd:dateTime)
}
```

Same `{type_filter}` and `{location_filter}` injection as the main query.
No `LIMIT`/`OFFSET` — returns the total item count for pagination math.

## Country codes — paginated query

**Source:** `src/main/event_resolver/persistence/repository/metadata_storage.py` — `_COUNTRY_CODES_QUERY`

```sparql
SELECT DISTINCT ?iso3 ?countryLabel WHERE {
  SERVICE wikibase:label { bd:serviceParam wikibase:language "en". }
  ?country wdt:P31 wd:Q6256.   -- instance of: country
  ?country wdt:P298 ?iso3.     -- ISO 3166-1 alpha-3 code
  {search_filter}
}
ORDER BY ASC(?iso3)
LIMIT {page_size}
OFFSET {offset}
```

### `{search_filter}` injection

When `q` is provided (sanitized via `_sanitize_search_term()`):

```sparql
FILTER(
  CONTAINS(LCASE(STR(?countryLabel)), LCASE("{sanitized_q}")) ||
  CONTAINS(LCASE(?iso3), LCASE("{sanitized_q}"))
)
```

When `q` is absent: empty string.

**Source:** `src/main/event_resolver/persistence/repository/metadata_storage.py` — `_COUNTRY_CODES_COUNT_QUERY`

```sparql
SELECT (COUNT(DISTINCT ?country) AS ?total) WHERE {
  SERVICE wikibase:label { bd:serviceParam wikibase:language "en". }
  ?country wdt:P31 wd:Q6256.
  ?country wdt:P298 ?iso3.
  {search_filter}
}
```

## Wikidata properties used

| Property | Wikidata ID | Used for |
|---|---|---|
| instance of | P31 | Matching event type |
| start time | P580 | Event start date |
| point in time | P585 | Fallback start date (for point-in-time events) |
| end time | P582 | Event end date |
| country | P17 | Event's country |
| location | P276 | Event's location entity |
| coordinate location | P625 | Location coordinates (WKT) |
| image | P18 | Event image URL |
| ISO 3166-1 alpha-3 | P298 | Country ISO code |
| country (Q6256) | Q6256 | Entity type for country filtering |
