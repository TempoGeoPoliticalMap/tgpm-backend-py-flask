2. `/v2/metadata/event-types` — static list of event type filter values
3. `/v2/metadata/regions` — static list of region filter values
4. `/v2/metadata/country-codes` — paginated, searchable list of country codes
5. Code-generation script updated to pull the OpenAPI spec from the remote URL
6. All Python dependencies updated to their latest stable versions
7. Full test coverage: unit tests for every new module + integration tests for all endpoints
8. A `docs/technical-design/` folder — architecture docs, SPARQL designs, mapping tables,
   and `agents.md` which is the primary onboarding guide for any AI agent or new engineer

**Backward compatibility constraint:** `/v1/events` must continue to work unchanged.

**Auth:** `BearerAuth` (JWT) is handled at infrastructure level and is out of scope.

**2. `to_sparql_values_block` static method** (L4) — must be decorated with `@staticmethod`
so it is callable as `WikidataClassEnum.to_sparql_values_block(...)` without an instance:

```python
@staticmethod
def to_sparql_values_block(selected_types: list[str] | None) -> str:
    if not selected_types:
        members = list(WikidataClassEnum)
    else:
        members = []
        for api_val in selected_types:
            member = API_TO_WIKIDATA_ENUM.get(api_val)
            if member is None:
                raise ValueError(f"Unknown event type API value: '{api_val}'")
            members.append(member)
    qcodes = " ".join(m.value for m in members)
    return f"VALUES ?itemType {{ {qcodes} }}"
```

> Note: `API_TO_WIKIDATA_ENUM` resolves both the `INTERNATION_ORGANIZATION` enum typo
> and the `SOURCES_OF_INTERNATIONAL_LAW` plural/singular mismatch in a single place.
> Do not add any other name-translation logic elsewhere in the codebase.

### STEP 5 — Create the versioned controller resolver

**New file:** `src/main/event_resolver/resolver.py`

The current `__main__.py` uses `RelativeResolver("event_resolver.controllers.events_controller")`,
which routes every operation to a single module. With multiple controllers for v2, a
custom resolver is needed.

```python
import importlib
from typing import Callable
from connexion.resolver import Resolver


class VersionedResolver(Resolver):
    """Routes connexion operations to controller modules based on operation-ID prefix.

    Routing rules (first match wins — order matters):
      "v1_events_"   → event_resolver.controllers.events_controller
      "v2_events_"   → event_resolver.controllers.events_v2_controller
      "v2_metadata_" → event_resolver.controllers.metadata_controller

    Resolved functions are cached after first lookup so importlib is not
    re-invoked on every request (H6).
    """

    _ROUTES = [
        ("v1_events_",    "event_resolver.controllers.events_controller"),
        ("v2_events_",    "event_resolver.controllers.events_v2_controller"),
        ("v2_metadata_",  "event_resolver.controllers.metadata_controller"),
    ]

    def __init__(self):
        super().__init__()
        self._cache: dict[str, Callable] = {}

    def resolve_function_from_operation_id(self, operation_id: str) -> Callable:
        if operation_id in self._cache:
            return self._cache[operation_id]
        for prefix, module_path in self._ROUTES:
            if operation_id.startswith(prefix):
                module = importlib.import_module(module_path)
                try:
                    fn = getattr(module, operation_id)
                except AttributeError:
                    raise ValueError(
                        f"Controller function '{operation_id}' not found in '{module_path}'"
                    )
                self._cache[operation_id] = fn
                return fn
        raise ValueError(f"No controller registered for operation: '{operation_id}'")
```

**Acceptance criterion:** Instantiating `VersionedResolver()` succeeds and
`resolve_function_from_operation_id("v1_events_get")` returns the function from
`events_controller`.

#### Default date range

If `timeslot_start` and `timeslot_end` are not provided, default to 30 days before today
through 30 days after today (matching v1 behaviour).

> **H4 — compute dates inside the function, not at module level.** The existing v1
> `events_storage.py` calculates `today`, `thirty_days_ago`, etc. as module-level
> constants, which freezes them at server startup. Do not repeat this pattern. Compute
> the default range inside `count_events_v2()` and `get_event_dao_list_v2()`:
>
> ```python
> def _default_date_range() -> tuple[str, str]:
>     now = datetime.now(timezone.utc)
>     fmt = "%Y-%m-%dT%H:%M:%SZ"
>     return (
>         (now - timedelta(days=30)).strftime(fmt),
>         (now + timedelta(days=30)).strftime(fmt),
>     )
> ```

#### SPARQL query — main

```sparql
SELECT DISTINCT
  ?item ?itemLabel ?itemType
  ?startTime ?endTime
  ?description
  ?imageUrl
  ?wikipediaUrl
  (GROUP_CONCAT(DISTINCT ?countryId;    separator="|") AS ?countryIds)
  (GROUP_CONCAT(DISTINCT ?countryLabel; separator="|") AS ?countryLabels)
  (GROUP_CONCAT(DISTINCT ?locationId;   separator="|") AS ?locationIds)
  (GROUP_CONCAT(DISTINCT ?locationLabel;separator="|") AS ?locationLabels)
  (GROUP_CONCAT(DISTINCT ?coordStr;     separator="|") AS ?coordStrs)
WHERE {
  SERVICE wikibase:label {
    bd:serviceParam wikibase:language "en".
  }

  # --- type filter (VALUES block injected from wikidata_class_enum) ---
  VALUES ?itemType { <Q_CODES_HERE> }
  ?item wdt:P31 ?itemType.

  # --- start time ---
  OPTIONAL { ?item wdt:P580 ?startTimeIndicator. }
  OPTIONAL { ?item wdt:P585 ?pointInTime. }
  BIND(IF(BOUND(?startTimeIndicator), ?startTimeIndicator, ?pointInTime) AS ?startTime)

  # --- end time ---
  OPTIONAL { ?item wdt:P582 ?endTime. }

  # --- description ---
  OPTIONAL {
    ?item schema:description ?description.
    FILTER(LANG(?description) = "en")
  }

  # --- image ---
  OPTIONAL { ?item wdt:P18 ?imageUrl. }

  # --- Wikipedia URL ---
  OPTIONAL {
    ?article schema:about ?item ;
             schema:isPartOf <https://en.wikipedia.org/> ;
             schema:name ?wpTitle .
    BIND(
      IRI(CONCAT("https://en.wikipedia.org/wiki/", ENCODE_FOR_URI(?wpTitle)))
      AS ?wikipediaUrl
    )
  }

  # --- countries ---
  OPTIONAL {
    ?item wdt:P17 ?countryEntity.
    ?countryEntity rdfs:label ?countryLabel.
    FILTER(LANG(?countryLabel) = "en")
    BIND(REPLACE(STR(?countryEntity), "http://www.wikidata.org/entity/", "") AS ?countryId)
  }

  # --- locations and coordinates ---
  OPTIONAL {
    ?item wdt:P276 ?locationEntity.
    ?locationEntity rdfs:label ?locationLabel.
    FILTER(LANG(?locationLabel) = "en")
    BIND(REPLACE(STR(?locationEntity), "http://www.wikidata.org/entity/", "") AS ?locationId)
    OPTIONAL {
      ?locationEntity wdt:P625 ?coord.
      BIND(CONCAT(STR(geof:latitude(?coord)), ",", STR(geof:longitude(?coord))) AS ?coordStr)
    }
  }

  # --- region filter (injected as VALUES ?filterCountry block) ---
  # <REGION_FILTER_INJECTED_HERE>

  # --- country filter (ISO alpha-3 → Wikidata via wdt:P298) ---
  # <COUNTRY_FILTER_INJECTED_HERE>

  # --- date range filter ---
  FILTER(?startTime >= "<TIMESLOT_START>"^^xsd:dateTime)
  FILTER(?startTime <= "<TIMESLOT_END>"^^xsd:dateTime)
}
GROUP BY ?item ?itemLabel ?itemType ?startTime ?endTime ?description ?imageUrl ?wikipediaUrl
ORDER BY DESC(?startTime)
LIMIT <PAGE_SIZE>
OFFSET <OFFSET>
```

#### SPARQL query — count

```sparql
SELECT (COUNT(DISTINCT ?item) AS ?total)
WHERE {
  VALUES ?itemType { <Q_CODES_HERE> }
  ?item wdt:P31 ?itemType.

  OPTIONAL { ?item wdt:P580 ?startTimeIndicator. }
  OPTIONAL { ?item wdt:P585 ?pointInTime. }
  BIND(IF(BOUND(?startTimeIndicator), ?startTimeIndicator, ?pointInTime) AS ?startTime)

  # <REGION_FILTER_INJECTED_HERE>
  # <COUNTRY_FILTER_INJECTED_HERE>

  FILTER(?startTime >= "<TIMESLOT_START>"^^xsd:dateTime)
  FILTER(?startTime <= "<TIMESLOT_END>"^^xsd:dateTime)
}
```

#### Filter injection rules

**Type filter** — always present; defaults to all 10 Q-codes if `types` is None or empty:
```sparql
VALUES ?itemType { wd:Q71266556 wd:Q1139665 ... }
```

**Region filter** — injected only if `regions` is non-empty. Resolve regions to country
Q-codes using `region_country_map.get_country_qcodes_for_regions`. Then inject:
```sparql
VALUES ?regionCountry { wd:Q145 wd:Q142 ... }
?item wdt:P17 ?regionCountry.
```

**Country filter** — injected only if `countries` is non-empty. Validate each ISO code
before injection (C1 — SPARQL injection guard): each value must match `^[A-Z]{3}$`;
raise `ValueError` for any non-conforming value. Then inject:
```sparql
VALUES ?iso3Code { "GBR" "FRA" }
?isoCountry wdt:P298 ?iso3Code.
?item wdt:P17 ?isoCountry.
```

When both `regions` and `countries` filters are present, apply them with `UNION` semantics
(event must match at least one):
```sparql
{
  VALUES ?regionCountry { wd:Q145 ... }
  ?item wdt:P17 ?regionCountry.
} UNION {
  VALUES ?iso3Code { "GBR" ... }
  ?isoCountry wdt:P298 ?iso3Code.
  ?item wdt:P17 ?isoCountry.
}
```

### STEP 8 — Create v2 mapper

**New file:** `src/main/event_resolver/mapper/event_v2_mapper.py`

Maps a SPARQL binding dict (from step 7) to a generated `EventEvent` model instance.

```
Input binding key        → EventEvent field
─────────────────────────────────────────────────────────────────────────────
item.value               → wikidataId  (strip URI prefix, keep "Q…" form)
                         → wikidataUrl (replace entity URI prefix with wiki URL)
itemLabel.value          → name
itemType.value           → type        (map Q-code to API enum string)
startTime.value          → startDateTime
endTime.value (optional) → endDateTime
description.value (opt.) → description
imageUrl.value (opt.)    → imageUrl
wikipediaUrl.value (opt.)→ wikipediaUrl
countryIds + Labels      → countries: list[Country]  (split on "|", zip)
locationIds + Labels     → locations: list[Location] (split on "|", zip, parse coords)
                         → regions: derived from country Q-codes via reverse lookup
                           of REGION_COUNTRY_QCODES
startDateTime vs now     → timeStateRelativeToNow (PAST / ONGOING / FUTURE):
                           - FUTURE:  startDateTime > now  (and endDateTime absent or > now)
                           - ONGOING: startDateTime ≤ now  AND (endDateTime absent OR > now)
                           - PAST:    endDateTime present  AND endDateTime ≤ now
```

**wikidataId extraction:**
```python
# Input: "http://www.wikidata.org/entity/Q178810"
wikidata_id = uri.replace("http://www.wikidata.org/entity/", "")
# Result: "Q178810"
```

```python

# Result: "https://www.wikidata.org/wiki/Q178810"
```

**event type mapping** — use `WikidataClassEnum` in reverse (Q-code → API string):
```python

# Iterate WikidataClassEnum values to find matching Q-code
# Return the API enum string (e.g. "WARFARE_AND_ARMED_CONFLICTS")
```

**Region derivation from countries:**
```python

# check which regions in REGION_COUNTRY_QCODES contain that Q-code.
# Collect unique matching regions.
```

**Country parsing from pipe-separated strings:**
```python
ids    = binding.get("countryIds",    {}).get("value", "").split("|")
labels = binding.get("countryLabels", {}).get("value", "").split("|")
countries = [Country(wikidata_id=i, name=n) for i, n in zip(ids, labels) if i]
```

**Location parsing:**
```python
ids    = binding.get("locationIds",    {}).get("value", "").split("|")
```

returns an `EventEvent` instance with all required fields populated.

```python
import math

from event_resolver.persistence.reposotiry.events_v2_storage import (
    count_events_v2,
    get_event_dao_list_v2,
)
from event_resolver.mapper.event_v2_mapper import map_binding  # H1: not `map`
from event_event_list_response_body import EventEventListResponseBody
from pagination import Pagination

MAX_PAGE_SIZE = 100  # H3: cap to prevent unbounded SPARQL LIMIT


def get_events_v2(
    page: int = 1,
    page_size: int = 100,
    types: list[str] | None = None,
    regions: list[str] | None = None,
    countries: list[str] | None = None,
    timeslot_start: str | None = None,
    timeslot_end: str | None = None,
) -> EventEventListResponseBody:
    # H3: sanitise pagination bounds before issuing any SPARQL query
    page = max(page, 1)
    page_size = min(max(page_size, 1), MAX_PAGE_SIZE)

    filters = {
        "types": types,
        "regions": regions,
        "countries": countries,
        "timeslot_start": timeslot_start,
        "timeslot_end": timeslot_end,
    }

    total_items = count_events_v2(filters)
    total_pages = math.ceil(total_items / page_size) if page_size > 0 else 0
    has_next_page = page < total_pages

    bindings = get_event_dao_list_v2(filters, page, page_size)
    events = [map_binding(b) for b in bindings]

    pagination = Pagination(
        page=page,
        page_size=page_size,
        total_items=total_items,
        total_pages=total_pages,
        has_next_page=has_next_page,
    )

    return EventEventListResponseBody(data=events, pagination=pagination)
```

```python
import re

def _sanitize_search_term(q: str) -> str:
    """Allow only alphanumeric, spaces, and hyphens; strip SPARQL-special characters."""
    if not re.match(r'^[\w\s\-]+$', q, re.UNICODE):
        raise ValueError(f"Invalid search term: '{q}'")
    return q.replace('"', '').replace('\\', '')
```

Call `_sanitize_search_term(q)` before building the FILTER clause, then inject:

```sparql
FILTER(
  CONTAINS(LCASE(STR(?countryLabel)), LCASE("<SANITIZED_Q>")) ||
  CONTAINS(LCASE(?iso3), LCASE("<SANITIZED_Q>"))
)
```

Return list of dicts like `[{"code": "GBR", "name": "United Kingdom"}, ...]`.

```python
    def test_no_qcode_appears_in_multiple_regions(self):
        # C2: guard against cross-region contamination introduced by wrong/corrected
        # Q-code pairs (e.g. Q117 = Ghana in SUB_SAHARAN_AFRICA and previously also

        from collections import Counter
        all_pairs = []
        for region, codes in REGION_COUNTRY_QCODES.items():
            all_pairs.extend((code, region) for code in codes)
        counts = Counter(code for code, _ in all_pairs)
        duplicates = {
            code: [r for c, r in all_pairs if c == code]
```

#### Section 5 — How to add a new endpoint

Step-by-step recipe an agent can follow without consulting any other document:

```
1. Confirm the endpoint exists in the remote OpenAPI spec at:
   https://raw.githubusercontent.com/TempoGeoPoliticalMap/tgpm-openapi/main/openapi.bundled.yaml
   If it does not, stop — request a spec update first.

2. Regenerate models: bash scripts/openapi.sh
   Verify the new model class(es) appear in src/main/@generated/openapi_models/models/

3. Register the operation ID in src/main/event_resolver/resolver.py
   Add a prefix → module entry to VersionedResolver._ROUTES.
   Prefix = the leading segment(s) of the operationId (e.g. "v2_events_" or "v2_metadata_").

4. Create a controller function in src/main/event_resolver/controllers/
   - File: <version>_<resource>_controller.py
   - Function name must EXACTLY match the operationId from the spec.
   - Accept parameters matching the spec's query/path parameters.
     connexion converts camelCase → snake_case when pythonic_params=True.
   - Return result.to_dict() — do not return model objects directly.

5. Create a service function in src/main/event_resolver/service/
   - Services must not import from controllers/ and must not call SPARQL directly.
   - All pagination math (totalPages, hasNextPage) is computed here.

6. If the endpoint reads from Wikidata, create SPARQL functions in
   src/main/event_resolver/persistence/reposotiry/
   - Provide a separate COUNT query function for pagination.
   - Build SPARQL dynamically from filter parameters using string templates.
   - Always set a User-Agent header on SPARQLWrapper.

7. If the endpoint returns a new model shape, create a mapper in
   src/main/event_resolver/mapper/
   - Input: SPARQL binding dict (keys as returned by SPARQLWrapper JSON format)
   - Output: generated model instance

8. Write tests:
   - Unit tests in src/test/python/unit/test_<module>.py (mock storage layer)
   - Integration tests in src/test/python/test_events/test_<resource>_controller.py
     (mock storage layer, test real HTTP routes)
   - No test may make a real network call.

9. Update docs/technical-design/ for any structural decision that is not obvious from code.
```

#### Section 7 — SPARQL result → model pipeline

The data flow for every Wikidata-backed endpoint:

```
HTTP request
    → connexion validates parameters against OpenAPI spec
    → controller function called with validated params
    → service function called
        → count_* SPARQL query (for pagination)
        → main SPARQL query with LIMIT/OFFSET
        → mapper called for each binding dict in results
            → SPARQL binding dict: {"item": {"value": "..."}, "itemLabel": {"value": "..."}, ...}
            → generated model instance (e.g. EventEvent)
        → Pagination model constructed from count result
        → response body model constructed (e.g. EventEventListResponseBody)
    → controller calls .to_dict() on response body
    → connexion serialises to JSON
HTTP 200 response
```

SPARQL binding dict structure (SPARQLWrapper JSON format):
```python
{
    "item":      {"type": "uri",     "value": "http://www.wikidata.org/entity/Q178810"},
    "itemLabel": {"type": "literal", "value": "Syrian Civil War", "xml:lang": "en"},
    "startTime": {"type": "literal", "value": "2011-03-15T00:00:00Z", ...},
    # absent key = optional field not bound for this result row
}
```

#### Section 8 — Pagination pattern

Every paginated endpoint uses two SPARQL queries:

```python
# 1. Count query (no LIMIT/OFFSET, no GROUP_CONCAT)
total_items = count_*(filters)

# 2. Main query (with LIMIT and OFFSET)
offset = (page - 1) * page_size
bindings = get_*_dao(filters, page, page_size)

# Pagination fields
total_pages  = math.ceil(total_items / page_size)
has_next_page = page < total_pages
```

The two-query approach is required because SPARQL does not support returning both the
total count and a page of results in a single query efficiently.

#### Section 9 — Filter injection pattern

How each query parameter becomes part of the SPARQL WHERE clause:

| Parameter | Injection mechanism |
|---|---|
| `types` | `VALUES ?itemType { wd:Q... }` block via `WikidataClassEnum.to_sparql_values_block()` |
| `regions` | Country Q-codes looked up from `region_country_map.get_country_qcodes_for_regions()`, then `VALUES ?regionCountry { wd:Q... } ?item wdt:P17 ?regionCountry.` |
| `countries` | ISO alpha-3 codes injected as `VALUES ?iso3Code { "GBR" }`, resolved via `?isoCountry wdt:P298 ?iso3Code. ?item wdt:P17 ?isoCountry.` |
| `timeslot_start` / `timeslot_end` | `FILTER(?startTime >= "..."^^xsd:dateTime)` |
| (no dates) | Default window: 30 days before today through 30 days after today |

When both `regions` and `countries` are provided, combine with `UNION` (OR semantics —
event matches if it belongs to any of the specified regions OR countries).

#### Section 12 — Known issues and hard constraints

| Issue | Constraint |
|---|---|
| `reposotiry` directory name typo | Do NOT rename — it would break all imports and Docker deployments. Reference as-is. |
| `INTERNATION_ORGANIZATION` enum typo | Do NOT rename the enum member — existing v1 code references it. The API string `INTERNATIONAL_ORGANISATION` is translated via `API_TO_WIKIDATA_ENUM` in `wikidata_class_enum.py`. |
| `SOURCES_OF_INTERNATIONAL_LAW` vs `SOURCE_OF_INTERNATIONAL_LAW` | Enum member is plural; API string is singular. Resolved by `API_TO_WIKIDATA_ENUM`. Never translate by enum member name directly. |
| Wikidata SPARQL rate limits | Keep `LIMIT` ≤ 1000; set `User-Agent = SPARQL_USER_AGENT`; set `setTimeout(SPARQL_TIMEOUT_SECONDS)`; surface HTTP 429 / 502 to the client. |
| SPARQL injection | All user-supplied values injected into SPARQL strings must be validated before interpolation: ISO alpha-3 codes via `^[A-Z]{3}$`; search terms via `_sanitize_search_term()`. |
| `page` / `page_size` bounds | Validate in every service function: `page = max(page, 1)`, `page_size = min(max(page_size, 1), MAX_PAGE_SIZE)`. `MAX_PAGE_SIZE = 100`. |
| Mock patch location | Always patch at the **usage site** (the module that imported the name), not the definition site. With `from X import f`, `X.f` is already bound — patching `X.f` after import is a no-op. |
| `map` as function name | The public mapper function is `map_binding`, not `map`, to avoid shadowing the Python built-in. |
| Module-level date computation | Compute `timeslot_start` / `timeslot_end` defaults inside the function body using `_default_date_range()`, not at module import time. |
| `geof:latitude` / `geof:longitude` | Wikidata SPARQL service extensions — verify they resolve before shipping. Fallback: parse WKT literal `Point(lon lat)` string manually. |
| BearerAuth (JWT) | Handled at infrastructure level. Never implement token validation in Python code. |
| `pythonic_params=True` | connexion converts camelCase query param names to snake_case for Python function parameters. Verify actual names for your installed connexion version. |
| Generated model names | `event_Event` → `EventEvent` (PascalCase). Always verify actual generated class names in `@generated/openapi_models/models/__init__.py` before writing import statements. |
| OpenAPI spec URL | Pin to a specific commit SHA in `scripts/openapi.sh`, not `main`. Update deliberately when adopting a new spec version. |

## Known risks and constraints

| Risk | Mitigation |
|---|---|
| Wikidata SPARQL endpoint rate-limiting | Keep `LIMIT` ≤ 1000 per query; set `SPARQL_USER_AGENT` and `SPARQL_TIMEOUT_SECONDS`; surface HTTP 429/502 to the client |
| SPARQL injection via user input | Validate ISO alpha-3 codes with `^[A-Z]{3}$`; sanitize search terms with `_sanitize_search_term()` before string interpolation |
| `page_size` DoS via unbounded LIMIT | Enforce `MAX_PAGE_SIZE = 100` in every service function before any SPARQL call |
| GROUP_CONCAT produces duplicate pipe-separated values | Use `DISTINCT` inside GROUP_CONCAT |
| Generated model class names may differ from expected (e.g. `EventEvent` vs `Event2`) | After step 2, inspect `src/main/@generated/openapi_models/models/__init__.py` to determine actual names before writing any import statements |
| connexion parameter name mapping (`pageSize` → `page_size`) | Verify with `pythonic_params=True` docs for the installed connexion version |
| Region → country Q-code table cross-contamination | All wrong Q-codes have been removed; the `test_no_qcode_appears_in_multiple_regions` test enforces uniqueness at CI time |
| Region → country Q-code table may be incomplete | Table covers ~170 countries; extend as needed; missing countries are silently excluded from region filter |
| SPARQL `schema:description` may return multiple languages | Filter on `LANG(?description) = "en"` as shown |
| `geof:latitude` / `geof:longitude` availability | These are Wikidata SPARQL service extensions; verify they work at `https://query.wikidata.org/sparql`; fallback to parsing the WKT literal `"Point(lon lat)"` if not available |
| OpenAPI spec changes silently at CI time | Pin the remote URL in `scripts/openapi.sh` to a specific commit SHA; update deliberately |
| Mock patch at definition site instead of usage site | Patch at `event_resolver.service.<module>.<name>`, never at `event_resolver.persistence.reposotiry.<storage>.<name>` |
